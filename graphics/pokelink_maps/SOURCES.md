# Non-Hoenn Map Asset Sources

This pack does not include ripped Pokémon map graphics. It records the source pages to use after the files are manually downloaded/provided.

## FireRed / LeafGreen Kanto and Sevii

Source page:
https://www.spriters-resource.com/game_boy_advance/pokemonfireredleafgreen/sheet/3864/

Sheet title:
`Town Map`

Use for:
- Kanto Town Map background
- Sevii Islands Town Map background
- Kanto/Sevii Fly-map style variants if needed

Notes:
- The sheet preview/source page shows raw maps and fly-map variants.
- Download the sheet and place it here before running Codex import work:
  `graphics/pokelink_maps/source/frlg_town_map.png`

## Import Preference

For the current ROM hack, prefer:

1. FireRed/LeafGreen `Town Map` sheet for Kanto and Sevii.
2. Gold/Silver `Maps (World Map & Flight)` sheet for a first Johto placeholder.
3. HGSS sheets only as redraw/reference material if you later want a more polished Johto map.
